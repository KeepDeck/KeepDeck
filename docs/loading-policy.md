# Политика чтения-загрузки браузера истории

Шапка над ступенями (docs/task-history-stages.md). Слово пользователя
2026-08-22: «политика загрузки данных нихуя непонятна». Здесь «загрузка»
= ЧТЕНИЕ: обещания о том, что и сколько читается, — с именем владельца
у каждого. Видимость — вторая колонка-следствие (чтение → что видит).

Форма каждой строки: [ОБЕЩАНИЕ | ВЛАДЕЛЕЦ + СОСТОЯНИЕ].
Состояния: ИСПОЛНЯЕТСЯ · ЧИНИТСЯ СТУПЕНЬЮ N · НАЛОГ (так и живёт,
названный) · НЕ ПОНЯТНО (решает: владелец). Голых обещаний без второй
колонки нет — иначе документ сам станет флагом без читателя.

## Шаг 0 — старт приложения (до первого списка)

| Обещание о чтениях | Владелец + состояние |
|---|---|
| До первого списка читаются: настройки, журнал воркспейса, список агентов — конечное число малых чтений | ИСПОЛНЯЕТСЯ (существующий boot) |
| Скрытые воркспейсы НЕ читаются вовсе | НЕ ПОНЯТНО — карты: веер присутствия папок бьёт и по скрытым. Владелец: круг, ступень-кандидат |

## Шаг 1 — первый кадр списка

| Обещание о чтениях | Владелец + состояние |
|---|---|
| Свои строки — журнал воркспейса: одно чтение, сразу | ИСПОЛНЯЕТСЯ |
| Прочие строки — индекс:page-zero двух полос на mount | ИСПОЛНЯЕТСЯ (до первой выборки каждой) |
| Сумма MB до первого кадра считается кем-то | НЕ СУЩЕСТВУЕТ — никто не считает. Владелец: круг (измерение; ОТДЕЛЬНАЯ метрика от индекс-бюджета №4 — режим не предрешает его политику) |

## Шаг 2 — скан (наполнение)

| Обещание о чтениях | Владелец + состояние |
|---|---|
| Один файл в батче разбирается ОДИН раз | НАЛОГ — сегодня В FALLBACK-ПУТИ (без usable index-title/summary) ДВА полных чтения+разбора (describe+content одного ref); fast-дорожки сокращают путь. ЧИНИТСЯ СТУПЕНЬЮ 2 (№8) |
| Бамп revision не перечитывает уже загруженную глубину | НАЛОГ — сегодня до 600 строк перезапроса на каждый бамп. ЧИНИТСЯ СТУПЕНЬЮ 2 (№9) |
| Присутствие папок спрашивается о новых путях, не обо всех | ИСПОЛНЯЕТСЯ (56fbf1f8) |

## Шаг 3 — листание списка

| Обещание о чтениях | Владелец + состояние |
|---|---|
| Долистывание читает СЛЕДУЮЩУЮ страницу, а не всё, что уже нарисовано | ИСПОЛНЯЕТСЯ (paging по engine) |
| Счётчик растёт от прочтённого, не от нарисованного | ИСПОЛНЯЕТСЯ (composition counts what it draws) |

## Шаг 4 — открытие сессии (клик → первый ход)

| Обещание о чтениях | Владелец + состояние |
|---|---|
| Клик → первый ход: звенья названы — head 64KB → sessions-index → файл (bounded) | ИСПОЛНЯЕТСЯ как механизм; глубина fallback — НАЛОГ (фолбэк до полного чтения), ЧИНИТСЯ СТУПЕНЬЮ 1 (describe-исключение) |
| Обрезанное чтение называется обрезанным (truncated читается) | НЕ СУЩЕСТВУЕТ — флаг приезжает и умирает. ЧИНИТСЯ СТУПЕНЬЮ 1 (truncated-читатель) |
| Пейджинг просмотра читает ДИАПАЗОН, не весь файл заново | НАЛОГ — сегодня перечитывание+перепарсивание всего файла на каждый скролл-клик. СТУПЕНЬ 3 (range); кэш-turns — вопрос пользователю ПОСЛЕ замера |

## Шаг 5 — поиск

| Обещание о чтениях | Владелец + состояние |
|---|---|
| Ввод читает ИНДЕКС, не файлы сессий | ИСПОЛНЯЕТСЯ (Rust index only) |
| Журнал фильтруется по своим полям без чтения файлов | ИСПОЛНЯЕТСЯ (journalRecordMatches) |
| Старые строки остаются до новых — без мигания | ИСПОЛНЯЕТСЯ (поднято из кода в политику) |

## Сквозной принцип-кандидат

«Сессия читается один раз — и раздаётся каждому, кто спрашивает»:
сегодня НЕ СУЩЕСТВУЕТ ни в чьей зоне — сессия-как-чтение не сущность
(карта, п.18). Это КАНДИДАТ-принцип: не решение, а направление.
Владелец решения: круг после ступеней 1-2; заявка в архитектуру —
ступень 3 (воркер как естественный дом once-reading).

## Чего этот документ НЕ делает

Не обещает скоростей (wall-time — замером, не словами); не решает
порядок ступеней (пользователь); не прячет «непонятно» — незнание,
названное здесь с владельцем, честнее знания, спрятанного в коде.
